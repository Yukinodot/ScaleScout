# 正式实验方案

初始 64 图运行用于查验实现和提出后续问题，不足以证明研究结论。

## 数据与隔离

- COCO train2017：用于确定调度参数，或训练未来的区域收益预测器。
- COCO val2017：冻结调度参数后报告完整评测，保留独立留出子集避免验证集反复寻优。
- VisDrone / 自建高分辨率图像：独立领域验证。先查许可与标注格式，再使用。
- 不把从 COCO train2017 取出的 COCO128 当独立泛化集。
- 若做学习式区域选择，GT 只在离线训练生成收益标签时使用，推理选择器只能接收原图和第一遍预测。

## 对照与消融

1. 同一模型、权重、输入尺寸、置信度、类别映射和合并规则。
2. K∈{0,1,2,3,5,8}，报告精度与实际总延迟之间的曲线。
3. 均匀分散覆盖、随机（至少五个种子）、纯线索、纯纹理、自适应和官方 SAHI 配置。
4. 单独关闭探索和重叠惩罚。初始 evidence/texture 消融保留了重叠惩罚，不能替代这两项实验。
5. 增加“整图提高输入分辨率”这一直接基线，防止局部放大的收益只是更多像素预算。
6. 将所有方法的模型调用数、处理像素和实际总耗时一起列出。固定调用数不能保证固定 FLOPs 或固定延迟。

## 指标

- 正式采用 pycocotools 的 COCO AP、AP_small/medium/large、AR，正确处理 crowd、ignore、maxDets 和 category_id 映射。
- 当前仓库提供的 fixed-confidence precision/recall 是诊断指标，原像素面积 <1024 定义小目标，匹配阈值为 IoU≥0.5，按置信度一对一匹配。
- 报告 FP 增加、重复框、截断框，以及全图发现而合并后丢失的目标。
- 计时：至少 20 次热身，多次重复，GPU 同步，固定设备和后端，报告中位数、P95 与峰值显存。
- 对图像进行配对 bootstrap，给出差异区间。多个数据集/预算组合需要考虑多重比较，不据单次正差异宣称显著。

## 可发展成进一步研究的方向

**学习额外区域的边际收益**：对训练图的候选切片离线执行模型，产生“新增正确检测减去新增误检”的收益标签。用轻量模型根据纹理、目标尺寸、置信度分布预测收益，再按预算选择。它需要与当前无训练启发式比较，并把选择器自身成本算入总耗时。

**序贯停止**：每检查一个区域，根据新增可靠目标与重复率决定是否继续。需要处理“尚未查看区域”的收益估计，不能用测试 GT 决定停止。

**跨尺度置信度校准**：在独立校准集上学习全图和切片分数的映射，减少多尺度误报。不能在评测集上选择校准阈值。

当前代码实现的是启发式版本；以上方向尚未实现、训练或验证。
