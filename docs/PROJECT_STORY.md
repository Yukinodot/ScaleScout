# 项目讲解提纲

## 一句话

在原 YOLOv8 课程实践基础上，实现一个有预算约束的局部复查系统，研究模型应该把额外计算花在图像的哪里。

## 可讲清楚的重点

**问题来源**：原项目观察到小目标检测弱。提高整个模型规模、提高整图分辨率和切片放大都有成本，因此先研究有限预算的区域选择。

**具体实现**：低阈值全图候选提供目标线索，纹理提供无候选区域的探索信号，重叠惩罚减少重复。所有预测还原到原图，按类别合并，并记录区域选择证据。

**验证方式**：全图、均匀、随机与消融使用同一检测器。均匀/随机/自适应有相同额外调用数。真实结果与失败图都可复查。

**个人贡献措辞**：原课程工作为小组项目；此仓库由 AI 协助建立。应在自己理解代码、复跑实验并开展后续改进后，再依据实际分工描述自己的贡献。

## 面试追问

- 为什么低置信度不等于不确定性？如何做校准？
- 全图完全漏掉的区域如何被探索到？纹理会带来什么偏差？
- 为什么固定模型调用数仍不能证明实际加速？
- 坐标如何还原？如何避免重叠切片重复计数？
- 召回提高而 precision 降低时是否仍有实际价值？
- 初始子集与完整 COCO AP 的证据强度有什么区别？
- 如何与 SAHI、ROI 门控和提高整图分辨率做公平比较？
